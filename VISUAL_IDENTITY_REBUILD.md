# OMEGA Visual Identity Rebuild

This branch exists to eliminate the generic developer-dashboard appearance without reducing runtime capability.

Design invariants:
- OMEGA reads as one computational instrument, not a stack of admin cards.
- Deep field space, asymmetrical hierarchy, orbit/continuity geometry, source motion, proof state, and instrument controls establish identity.
- Gold + teal are functional signal colors, not decorative rainbow styling.
- Major surfaces remain visually distinct while sharing the same sovereign material language.
- Mobile collapses cleanly to one-column composition without covered controls or horizontal dependency.
- Motion is restrained and disabled by `prefers-reduced-motion`.
- No runtime capability, truth gate, Drive release authority, Cloudflare portability, Hybrid Link proof boundary, or Earth external-source boundary is weakened by presentation changes.

The visual layer is loaded last so it can replace generic shell styling without forking application logic.
