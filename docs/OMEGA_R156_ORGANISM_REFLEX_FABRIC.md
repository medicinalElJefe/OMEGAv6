# OMEGA R156 — Organism Reflex Fabric

R156 generalizes a behavior that first became concrete in the optical stack: a specialist result can be locally strong and still violate the stronger domain of a downstream authority. The correct response is not to erase the result, flatten the specialist, or silently promote it. The result must return to the organism as evidence, preserve its invariant state, carry the contradiction as history/scar, route to the authority that owns the stronger domain, and change the next bounded search.

## The larger realization

OMEGA is not only a collection of routes, modes, solvers, clouds, visuals, executors and proof gates. R155 already establishes one canonical product with 15 current capability families, while the older convergence inventory preserves 24 historical software families. The missing organism-level behavior is a universal reflex protocol across those families.

The generic loop is:

`OBSERVE → CLASSIFY RESIDUAL → ROUTE BY FAMILY AUTHORITY → INVOKE → RETURN → VERIFY → CARRY SCAR → RECONTEXTUALIZE → REPARTITION`

This sits inside the already established continuity operator:

`PARTITION → EXCHANGE/TRANSFORM → INVARIANT CARRY → SCAR/RESIDUAL CARRY → RECONTEXTUALIZE/REPARTITION`

and does not replace the canonical stage chain. R125 remains the only CanonState admission authority.

## Why the optical result matters beyond optics

The live R153.2 reduced-order optimizer improved its own objective and returned a geometry that satisfied its local pitch constraints. The stronger R41/R43 RCWA geometry domain then exposed a cross-layer mismatch. R153.3 responds by enforcing the stronger full-wave domain.

R156 extracts the general rule from that event:

> A returned winner is not the end of a mission. It is a new observation at the boundary between capability families.

That same rule applies to every family:

- a PC/browser action that lacks an authenticated host return becomes `EXECUTION_UNPROVEN` and routes to `FEDERATION_MACHINE`;
- a solver result outside a stronger solver domain becomes `DOMAIN_MISMATCH` and routes to the stronger computation/evidence family;
- a missing or stale source becomes `MISSING_EVIDENCE` or `STALE_NOW` and routes to evidence/NOW authority;
- an overloaded swarm plan becomes `CAPACITY_PRESSURE` and routes to relative-capacity and mission-graph planning rather than pretending logical fanout executed;
- a UI regression becomes `INTERFACE_OBSTRUCTION` and routes to interface preservation without deleting the underlying specialist surface;
- a reproducible software defect becomes `SOFTWARE_DEFECT` and may route to bounded self-development, while truth law, evidence semantics and CanonState rules remain immutable to that repair path;
- a cross-source contradiction becomes `TRUTH_CONTRADICTION` and is preserved as evidence/scar rather than averaged into false certainty.

## Invariant carry and scar carry

Every R156 reflex preserves:

- source capability family;
- source authority and truth boundary;
- canonical address when present;
- packet identity when present;
- R125 as canonical admission authority;
- residual identity, type, severity and evidence reference;
- previous scar lineage;
- bounded target family route;
- cycle detection and maximum hop count.

A scar is historical/routing state, not CanonState and not a cryptographic execution receipt. Existing proof systems remain responsible for execution and replay identity.

## Reflex actions

R156 reuses the established behavioral vocabulary:

- `STAY` — no cross-family residual requires action;
- `TURN` — route to a stronger or more appropriate family;
- `ESCALATE` — severe contradiction/pressure requires broader authority or human review;
- `HOLD` — required proof/evidence is absent or a routing cycle has formed;
- `REJECT` — reserved for explicitly invalid/refused states rather than quietly dropping them.

The action is planning state. It is not proof that any target executed.

## Bounded nervous system

The reflex fabric is intentionally bounded. A route has a maximum hop count, detects repeated families, and stops in `HOLD_FOR_CYCLE_REVIEW` when all next targets would repeat the current path. This prevents a contradiction from causing an infinite autonomic loop.

The reflex fabric does not create 1,728 physical clouds or agents. The existing seed → organ → branch → cell → lane hierarchy remains a logical execution organization until actual workers/executors are proven.
