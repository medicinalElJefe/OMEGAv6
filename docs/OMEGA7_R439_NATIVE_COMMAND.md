# R439 · Native Ask OMEGA Runtime

R439 makes `Command Center` the second OMEGA7 native route, after Earth.

## Product objective

The OMEGA7 front door should feel current and understandable without flattening the accepted OMEGA runtime.

Standard view therefore presents:

- one prompt;
- a small set of familiar task starters;
- one result;
- one next action;
- optional “Why this result?” disclosure.

Advanced and Canon depth retain the existing `OmegaCommandDeck` technical instrument.

Both projections use the same source packet and execution path.

## Execution authority

Native Ask OMEGA preserves:

```
current source packet
  -> source-backed mode summary
  -> Full Overall mode plan
  -> route preview
  -> chat/runtime execution
  -> bounded returned result
```

The exact same context object is sent to route preview and chat.

Route preview must occur before generation.

Missing evidence is not invented.

Presentation has no CanonState mutation authority.

## Continuity

The native command workspace reads the accepted `omega.v6.address` state and current corpus runtime rather than creating a parallel OMEGA7 corpus.

The prompt draft continues to use the accepted browser-local draft key.

OMEGAv6 Command Center remains available as rollback until parity gates are complete.

## Current native set

- Command Center
- Earth Now

All other routes remain bridged.

This is intentional. Native migration proceeds by proved family rather than visual replacement.
