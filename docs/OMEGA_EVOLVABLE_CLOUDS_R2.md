# OMEGA Evolvable Clouds R2

## Purpose
The federation is deliberately not a monolith. Each cloud is a replaceable specialized surface around stable, versioned contracts.

## Stable core
- CanonState authority remains OMEGAv6 unless explicitly migrated by a governed release.
- Atlas addresses remain 12^4 address-resolution coordinates.
- Packet lineage, proof state, scar/history, solver identity and source SHA cross every node boundary.
- Browser scalar visualization never masquerades as full-wave validation.

## Independent polish lanes
Each node may independently change visual design, navigation, responsive behavior, renderer, implementation language, storage, deployment provider, solver version, caching, batching and internal APIs.

A node upgrade is compatible when it still advertises at least one mutually supported packet/result schema and preserves required semantics. Breaking changes publish vNext beside the previous version for a migration window.

## Promotion sequence
1. Build on an isolated branch/deployment.
2. Run node-local tests.
3. Run federation contract tests.
4. Verify live endpoint and capability manifest.
5. Compare performance and proof behavior against current production.
6. Promote only the upgraded node.
7. Preserve rollback target.

## Two-tier optical work
Tier 1 compiles and screens the 20,736-address optical candidate space with reduced-order/scalar models. Only proof-admissible top-ranked candidates enter Tier 2. Tier 2 routes periodic/local-periodic candidates to RCWA and difficult coupling/edge/high-scar candidates to FDTD. FEM remains an optional specialized route.

## Full-wave truth boundary
A Tier-2 job is not validated merely because it ran. Admission requires solver convergence metadata, material model identity, numerical settings, reproducible lineage, and eventually comparison with independent measurement for fabrication claims.

## Long-term federation
Genesis proposes. Optical compiles/screens. Sovereign solves. OMEGAv6 admits and records. Any one implementation can later be redesigned without flattening the others.
