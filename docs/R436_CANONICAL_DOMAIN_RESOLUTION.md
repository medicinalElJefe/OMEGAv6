# R436 · Canonical Domain Resolution Spine

R436 makes the live OMEGAv6 domain engines emit one common, proof-bounded
resolution contract:

`NodeState -> TransitionRecord -> Branch -> Ledger`

It is additive to R435 and does not replace R125 CanonState admission, R240
exact-head source promotion, R245 governed self-build, or the canonical
production deployment workflow.

## Authority

Every input is classified as one of:

1. `MEASURED`
2. `DERIVED_STANDARD`
3. `DERIVED_LENS`
4. `HYPOTHESIS`

Physical vetoes run before Dewey/Canon branch scoring. A failed physical check
cannot be rescued by a high CΩ/Φ score.
