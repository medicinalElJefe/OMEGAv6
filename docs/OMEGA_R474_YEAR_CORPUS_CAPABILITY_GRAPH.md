# OMEGA R474 — Year-Corpus Capability Graph

R474 makes **capability lineage** the canonical unit of convergence. R473 remains the current-executor binding layer beneath it; routes and menus are presentation surfaces, not definitions of what OMEGA is.

## Architecture

OMEGA = Canonical State + Calculus + Developmental Continuity + Knowledge/Atlases + Execution + Rendering + Traversal + Memory + Intelligence + Applications + Proof + Recovery

Every recovered R473 lineage is compiled into a typed R474 node carrying:

identity → lineage → function → strongest implementation → evidence → truth class → dependencies → current executor → presentation surface → remaining gap → supersession relation

Artifact roles are explicit: ENGINE, MODEL, ATLAS, DATASET, EXECUTOR, RENDERER, WORKSPACE, APPLICATION, NATIVE_TARGET, PROOF, RECOVERY, DONOR and SCAR. A capability may have several artifact roles, but a view never becomes authority merely because it exposes one.

## Strongest-valid resolution

Implementation selection is constrained before scoring. A candidate is eligible only when truth-valid, proof-valid, dependency-compatible and governance-valid. Quality wins among admissible candidates; chronology is only a tie-breaker. Therefore an older proven implementation can correctly defeat a newer regression or unproven rewrite.

## Capability conservation

Every promotion can be compared against the prior graph. A capability that disappears must be explicitly resolved as SUPERSEDED, INTENTIONALLY_DEPRECATED, PLATFORM_SPECIFIC or QUARANTINED. Silent loss and known REGRESSION block conservation.

This separates three historically conflated failures:

- capability loss — the function itself disappeared;
- executor loss — the capability is known but no current executor performs it;
- presentation loss — execution exists but the current UI no longer exposes it.

## Authority boundaries

- R125 remains sole CanonState admission authority.
- R142 remains execution-receipt authority for current handoffs.
- presentation surfaces are generated from capabilities and never define canonical capability.
- renderers remain lawful state projection, not evidence creation.
- representational dimensional scales remain address/resolution hierarchies unless independently physically bound.
- truth-gated provider/device/native work remains gapped until returned proof exists.
- scars, rejections and contradictions remain part of supersession history.
- autonomous convergence retains one-current-lineage discipline, ci.yml sole production-write authority, and no autonomous governance/test/secret/deployment-authority edits.

## Corpus boundary

R474 types the recovered R473 corpus immediately. It deliberately does **not** pretend that every external archive or Drive artifact has already been exhaustively fingerprinted. New archive evidence enters as donor/scar material and must be independently resolved before becoming a strongest implementation. This prevents corpus recovery from becoming silent authority promotion.
