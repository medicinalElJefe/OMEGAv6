# R127 Hybrid security boundary

The cloud/PC bridge is not a general remote shell. The Windows agent executes only registered OMEGA operation families inside the approved root. Paths are normalized and root-checked; execution output is bounded and returned as receipts. UI automation operations remain unavailable unless the optional signed desktop adapter exists. Solver readiness is independent of general Hybrid readiness.

R127 additionally authenticates the connector's downloaded agent bytes against a digest declared by canonical OMEGAv6. This protects the transition from cloud-served source to local execution from partial-response, wrong-content and stale-substitution failure modes. It does not claim protection against a fully compromised local operating system or compromised canonical deployment credentials.
