## Authority distinction
The Mode188 workbook is **not** the same file as `Time_Mandala_of_Matter_20736D_Excel_Engine.xlsx` (Drive `1L4yQ8einYFoUsbNniz_JI0tNnt-ngKD6`). The Mode188 workbook separately contains a 1,728-base-state table, 20,736-row runtime atlas, 20,736-row database snapshot, runtime controls and proof sheets. Do not silently equate their coordinate meanings, copy one regulation axis into the other, or call the R604 dispatch the full Mode188 runtime.

The repository's `src/driveCanonSource.ts` records 10,368 coupling edges, 416 graph edges, 288 motion frames and source CSV names. Those are historical source **metadata counts**, not a verified import of the underlying edge or motion records. The recovered workbook sheet extents likewise prove sheet structure, not row-by-row formula parity or topology execution.
