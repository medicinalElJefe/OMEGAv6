# OMEGA R347 — Human-Correlated Traversal Cockpit

## Purpose

R347 makes Traversal and Cockpit readable as one human visual instrument without replacing established source, calculus, proof, motion, Hybrid, Earth, SAR, or deployment authority.

The primary visual model is:

worldline + field + scar/history + admissible future cone

R347 is a projection layer. It does not admit CanonState, create external evidence, create physical measurements, or rename model channels as measured physics.

## Human interaction model

1. Current state is the anchor.
2. The admitted route is the worldline.
3. Past states remain visible as scar/history.
4. Alternatives form a future cone around the current route.
5. Uncertainty is spatialized as a halo from q and Λ.
6. Evidence controls clarity/focus.
7. Resolution is visible as nested context, not a physical-dimension claim.
8. Logical time has its own scrubber.
9. Observer rotation and zoom change projection only; they never mutate source state.
10. Clicking an admissible future is an explicit state-selection action.

## Time authority

R347 maintains three separate clocks:

- ROUTE_STEP: canonical logical traversal order.
- DISPLAY_ONLY: animation/render clock.
- external eventTime: admitted only from a source-bound observation packet.

A route index may never be labeled as a real-world timestamp.

## Energy authority

Default:

- MODEL_PROXY
- label: MODEL INTENSITY
- source: unified light intensity / action proxy

A physical-energy display is admitted only when an observation packet includes source identity, event time, receive time, coordinate/frame identity, explicit units, numeric physical-energy value, and provenance lineage.

Only then may the node carry UNIT_BOUND_PHYSICAL.

## Real-time packet contract

TraversalObservationPacketR347 is the integration boundary for SAR, Earth, sensor, simulation, or other live data.

A packet that fails source/time/frame/provenance validation is ignored by the physical channel and cannot override the canonical packet.

Real-time ingress therefore changes evidence content, not the visual law.

## Visual-first rule

The main canvas must remain unobstructed. Telemetry belongs in the temporal ribbon, future-support strip, compact numeric readout, controls below the stage, and expandable visual grammar.

No HUD card is allowed to cover the primary field.

## Mathematical boundaries

R347 must never:

- use random geometry;
- infer physical dimensions from atlas resolution;
- infer physical energy from model intensity;
- infer event time from route index;
- infer probability from future support;
- convert an observer transform into a state mutation;
- hide unknown evidence behind a decorative value;
- silently replace R100/R35/R23 authority;
- treat rendering as proof.

## Expansion path
