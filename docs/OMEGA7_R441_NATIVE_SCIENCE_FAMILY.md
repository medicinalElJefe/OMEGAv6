## Atomic / chemistry source gate

R441 does not convert archive metadata into live atomic evidence.

The workspace invokes the existing typed atomic/chemistry R436 source gate.

If no typed element/source record has been supplied, OMEGA7 presents:

`MORE EVIDENCE NEEDED`

and the underlying R436 state remains `OBSERVE_ONLY`.

This is a deliberate fail-closed product behavior.
