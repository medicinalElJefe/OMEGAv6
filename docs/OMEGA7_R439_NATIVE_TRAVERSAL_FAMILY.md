## Shared state authority

`omega.v6.address`

## Cross-navigation

Native capability-to-capability requests emit `omega7-route-request`.

The OMEGA7 root resolves that request through the same capability registry:

- if the destination is native, it remains in OMEGA7;
- if the destination is still bridged, the accepted OMEGAv6 compatibility path remains available.

No native component receives authority to bypass the capability registry.
