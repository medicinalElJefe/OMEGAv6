# OMEGA R473 — Year-Corpus Full-System Execution Convergence

## Purpose

R473 changes the unit of preservation from **latest menu/version** to **capability lineage**.

OMEGA has accumulated valid work across multiple generations: runtime/OS families, mathematical and relational calculus, atlas geometries, temporal/developmental systems, render/media engines, Earth/SAR, scientific atlases, biology, language, SAI/AI, Hybrid/native execution, archive/recovery, autonomous development, operational workstations, and proof/governance.

A capability is no longer considered preserved merely because its name or donor file remains in an archive.

## Operational rule

Every materially valid lineage must resolve to exactly one of:

1. **EXECUTES_NOW** — the contribution is carried by a current canonical executor.
2. **EXECUTES_AS_ADAPTER** — the historical contribution is translated into the current executor while preserving its distinct operator/model intent.
3. **TRUTH_GATED** — execution requires a provider, device, native solver, hardware surface, or empirical source that is not currently proven available.

Historical age alone is never a reason to route a capability to Archive Operators.

Archive Operators remains the current executor only for archive/recovery work itself.

## Active handoff

Selecting a lineage in `YearCorpusConvergenceR473` emits `OMEGA_CORPUS_EXECUTION_INTENT_R473`.

The intent includes lineage id/name, current route, current operation, execution state, domain, timestamp, and `canonicalMutation:false`.

`OmegaWorkstationFullV2` consumes and retains that intent across navigation, exposes it in the destination workspace, includes it in assistant/runtime context, and writes it into route-open operation receipts.

The intent is context for execution. It is not a second state authority.
