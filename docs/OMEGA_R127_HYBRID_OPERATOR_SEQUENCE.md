# R127 operator sequence

The ordinary operator sequence is intentionally short:

1. Open the canonical OMEGAv6 Hybrid Link destination.
2. Click **FIX CONNECTION NOW** once.
3. Click **DOWNLOAD R127 ZERO-DRIFT CONNECTOR**.
4. Open `START_OMEGA_PC_LINK_R127_ZERO_DRIFT.cmd` on the Windows PC.
5. Keep the connector window open while the PC should participate.
6. Accept `PC ONLINE` only after the browser receives the current authenticated heartbeat proof.

Do not use an older connector if the R127 connector exists. Do not edit the pairing code into another script. Do not substitute another host when canonical OMEGAv6 is unreachable. A failure must remain a visible failure until the failing stage is corrected.
