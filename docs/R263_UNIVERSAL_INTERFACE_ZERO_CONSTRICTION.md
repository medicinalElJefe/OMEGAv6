# R263 Universal Interface — zero-constriction contract

R263 is an additive commercial experience layer over production-green R262. It must increase capability without reducing the visibility, reachability, screen area, operational ordering, or authority of established OMEGA tools.

## Desktop and mobile

The full nine-activity Universal Interface is shown on Home. Specialist surfaces receive a compact intent row by default so Earth, Hybrid, Build, Proof and other specialist applications retain their working viewport. The full activity/classification/plane fabric remains reachable through More. Mobile compact mode removes decorative brand copy, keeps the intent field and a 44px expansion control, and does not horizontally clip the specialist stage.

## Hybrid operational priority

Hybrid keeps every established runtime surface. Primary operation remains ordered ahead of longitudinal telemetry/development surfaces: authenticated connection → host intelligence → resource governor → connected action → outcome closure → first-hand host effects → R237 command deck → R141 proof closure. Execution motion, woven continuity, experience ledger, parallel development and lineage remain present afterward. R212 host effects → R237 command → R141 closure remains an inherited invariant.

R255/R262 observation and adaptive-development surfaces may never displace, hide or replace the established R247/R254/R212/R237/R141 operational path.

## Menu and display reachability

R257 Experience modes, R82 workspaces/lenses, the 44-route specialist registry and the R88/R94 persistent navigator remain reachable. R263 does not create a replacement route registry and does not filter routes out of All Systems. Immersive mode intentionally removes nonessential chrome but retains the existing truth ribbon and explicit exit control.

## Truth and authority

Information classification travels with information: Observed, Derived, Reconstructed, Simulated, Forecast, Reference, Generated, User Asserted and Unknown are presentation/provenance classes. Changing an activity or view cannot upgrade evidence class or create execution authority.

R147 dispatch, R141 return proof, R240 source promotion, R125 CanonState admission and `ci.yml` production deployment remain unchanged.
