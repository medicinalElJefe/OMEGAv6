# OMEGA Missing Capability Convergence Matrix · R386

This matrix is a recovery/convergence authority for capabilities already requested, previously built, recovered from archives, or repeatedly identified as incomplete. It does not create new authority. A capability counts as restored only when it is integrated into the current one-system runtime, reachable from the canonical 44-route / 12-master-menu navigation where appropriate, passes exact-head proof, and is live-verified when external/device execution is part of the claim.

## A. One-system runtime convergence
- [ ] One launcher/runtime/state authority across cloud, browser, Hybrid and native-host surfaces.
- [ ] One renderer contract spanning FIELD, SURFACE, SKIN, GRAPH, ASSEMBLY, MATERIAL, EVIDENCE, CANON and TRAVERSAL views without duplicate renderers or shadow viewports.
- [ ] Capability states normalized as READY / AVAILABLE_NOT_CONFIGURED / OPTIONAL_NOT_INSTALLED / DEGRADED / FAILED instead of hidden replacement surfaces.
- [ ] Renderer fallback chain OpenGL 4.5 → 4.3 → 3.3 → CPU proven without application crash or unrelated placeholder substitution.
- [ ] Cumulative imports / authorities / renderer / GPU / persistence validation available from one current proof surface.

## B. Navigation and interface inheritance
- [x] Canonical 44-route registry through 12 recovered master menus.
- [ ] Every route proves functional inheritance, not menu presence alone: usable controls, state/output, proof, failure/recovery path.
- [ ] All previously buried/lost controls recovered and reconciled; no duplicate authorities or hidden unreachable functions.
- [ ] Mobile + desktop parity for every route, submenu, disclosure, overlay and visual layer.
- [ ] Unified operation ribbon / mission-aware navigation / task workspace rather than disconnected mini-app behavior.
- [ ] No panel-level blocking failure wall may replace a canonical product surface; root cause is repaired at the failing layer.

## C. Earth / space / environment
- [ ] Full multi-resolution Earth fusion beyond the current bounded provider field: satellite/radar/ocean/lightning/precipitation/fire/aerosol/seismic/space-weather/orbital evidence.
- [ ] Weather workspace/tab with location targeting, hourly + weekly views, source-return provenance, satellite/context integration and bounded forecast uncertainty.
- [ ] Seamless Earth → region → city → street → ground traversal with returned evidence where available.
- [ ] Ground/street imagery providers and source fallback behavior live-verified without generated substitute imagery.
- [ ] Earth views use adaptive LOD and bounded render cost while preserving source fidelity.

## Promotion rule
A checked source item is not automatically a completed product item. Completion requires current exact-head proof, governed merge/promotion, and live verification for every claim that depends on production, an external provider, or a physical device.
