# OMEGA R130 — Maximum-Capacity Organism

R130 is the execution/coordination layer that makes the existing OMEGA hierarchy behave like one organized body without flattening its independent parts or weakening the proof boundary.

## Preserved foundation

R130 starts from the current mainline and preserves the admitted R129 reproducible empirical experiment runtime, R128 empirical calibration/replay ledger, R127 evidence→execution→proof fabric, R126 causal interaction/relativity and maximum convergence, R125 accuracy/admission and autonomic routing, R124 governed self-build, R123 organism/living runtime, R122 computed reality, R121 stateful swarm/Earth, federation, Hybrid/Sovereign, Genesis, Optical and the inherited mode/canon stack.

The new layer does not replace those systems. It supplies the missing organism-scale coordination fabric above the real 1,728 stateful cell objects.

## Body topology

`1 seed → 12 organs → 144 branches → 1,728 stateful cells → 20,736 execution lanes`

20,736 is an execution/address-resolution level, not a claim of literal physical dimensions.

At FULL BODY scope the R130 task graph contains:

- 1 mission frame;
- 1,728 cell tasks;
- 1 whole-cell mesh barrier;
- 144 branch cross-checks;
- 12 organ syntheses;
- 12 inter-organ exchange tasks;
- 1 proof return.

Total: **1,899 execution tasks** over **1,728 real cell Durable Object identities**.

## Seven execution waves

1. `FRAME` — seal intent, scope, budgets and evidence identity.
2. `PARALLEL_CELL_WORK` — independent specialist cell execution.
3. `MESH_BARRIER` — no branch synthesis begins until every selected cell has either returned or left a scar.
4. `BRANCH_CROSSCHECK` — each represented branch reads its member candidate memory plus bounded semantic cross-branch synapses and checks contradiction/evidence/invariant carry.
5. `ORGAN_SYNTHESIS` — branch checks reconverge by organ.
6. `INTERORGAN_EXCHANGE` — every represented organ compares against the complete represented organ synthesis set.
7. `PROOF_RETURN` — one whole-body result packet returns with disagreement, scars, evidence authority, missing proof and execution receipts intact.

## Maximum capacity without 1,728 model calls

R130 deliberately separates **cell count** from **paid/external model calls**.

All 1,728 cells can participate while most work remains deterministic/stateful. Workers AI remains hard-capped at 12 calls per mission. Model calls are concentrated at higher-value organ/inter-organ/final synthesis points. Genesis and Optical remain specialist machine paths. Cell dispatch is bounded-concurrent with a default width of 24 and a hard ceiling of 48.

That gives the body substantial parallelism without uncontrolled spend, unbounded provider retries or the false claim that every cell is a separate foundation model.

## Scope and scale

Scope describes *where* the organism may operate:

- BODY — up to all 1,728 cells;
- ORGAN — exactly one 144-cell organ address space;
- BRANCH — one 12-cell branch;
- CELL — one exact cell.

Scale describes *how much* of that scope is selected:

- SOLO — 1;
- BRANCH — up to 12;
- ORGAN — up to 144;
- FLOCK — up to 288;
- BODY/FULL — the full chosen scope;
- ADAPTIVE — uses causal compute pressure but caps automatic BODY escalation at 288 unless full-auto is explicitly authorized.

This fixes the prior ambiguity between branch-scale (12 cells) and organ-scale (144 cells).

## Operational synapses

Synapses are no longer decorative metadata. Every cell has eight bounded neighbor addresses drawn from:

- same-branch regulation neighbors;
- adjacent phase neighbors;
- adjacent organ neighbors;
- proof-side routing;
- coordination-side routing;
- deterministic fallback links when semantic links collide.

After the whole-cell barrier, branch cross-checks read candidate memory from selected cross-branch synapses. This creates lateral communication without an explosive all-to-all dependency graph.

## Candidate memory and scars

The R130 cortex stores:

- mission DAG state;
- per-task candidate memory;
- per-cell latest candidate memory index;
- receipt hashes;
- cell and whole-mission Merkle roots;
- event stream;
- scar/failure carry;
- checkpoint SHA-256;
- execution semantic hash.

Failed tasks do not disappear. Deterministic work receives one bounded retry; persistent failure becomes a scar packet that downstream cross-checks can observe.

## R127 / R128 / R129 integration

A completed R130 mission emits an R127-compatible execution evidence packet containing cell completion/failure counts, cell Merkle root, checkpoint hash, timestamp, source and an explicit internal-integrity verification scope. It remains `R130_EXECUTION_RECEIPT_NOT_CANON`.

R130 also emits an `executionSemanticHash` suitable as an upstream proof/replay identity for the R129 experiment ledger.

Crucially, internal cortex execution receives **zero R128 external-validation credit**. An internal receipt is not an external holdout dataset, independent reproduction or empirical measurement. R128's external-data discipline remains intact.

## Canonical authority

R130 cannot mutate CanonState. The authority chain remains:

`candidate computation → execution receipt → R127 proof fabric → independent verification / empirical evidence when required → R128/R129 replay evidence where applicable → R125 / OMEGAv6 admission`

Execution quorum, model synthesis, internal integrity hashes, replay identity and swarm agreement are never promoted into universal truth merely because the body completed a mission.
