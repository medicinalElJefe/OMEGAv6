# R317 Product Composition Repair

R317 fixes the visible product composition without changing Canon, proof, dispatch, execution, deployment, or evidence authority.

## Defect

The root application mounted the R257 experience shell around R71. R71 already owns the canonical R82/R88 product navigation. The result was multiple navigation generations visible at once.

## Repair

- R71 + R88 remain the single visible canonical product navigator.
- R257 provider/context remains mounted so experience state and compatibility are retained.
- R257 duplicate outer navigation chrome is no longer mounted by App.
- Accumulated routes remain reachable through R82/R88.
- Runtime/system evidence remains available under the collapsed `System status` disclosure rather than occupying the product surface.
- Specialist workstation behavior remains unchanged.

## Authority boundary

This is a composition repair only. It creates no new CanonState, proof, evidence-admission, execution, dispatch, deployment, or runtime authority.
