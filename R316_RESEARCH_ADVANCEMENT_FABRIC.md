## Added software capability
1. Expiring capability leases with child-scope non-escalation; heartbeat never extends authority by itself.
2. Typed proof receipts spanning identity, authorization, execution, artifact, state-before/state-after, policy, observer and parent receipt.
3. Durable mission lifecycle: QUEUED → CLAIMED → STARTED/HEARTBEATING → RETURNED → VERIFIED → COMMITTED, with bounded REQUEUED/FAILED/REVOKED branches.
4. ExecutionEnvironment separates orchestration from LOCAL_PC/CLOUD/MOBILE/other execution skins; the environment is never canonical state owner.
5. Visual/web/file observations cannot expand tool authority; PIXELS are evidence, not authorization.
6. CI trust risk explicitly blocks the conjunction of untrusted input + privileged execution + secret reachability.
7. FabricationTransform carries CD, etch, overlay, roughness, sidewall and related process scar separately from ideal geometry.
8. Optical field state carries wavelength, intensity, phase, direction and Stokes polarization as first-class coordinates.
9. Candidate identity hashes geometry + relational transform + material + boundary conditions; relative orientation/offset are not cosmetic.
10. Solver routing preserves the existing FAST → RCWA/FDTD/FEM architecture and adds explicit regimes for finite, transient, nonlinear, anisotropic and time-varying cases.
11. Model promotion requires fast/rigorous agreement, numerical convergence, energy residual and fabrication robustness; it still does not constitute empirical proof.
12. ExperimentEpisode retains prediction/measurement residuals instead of erasing failed hypotheses.
13. ScenePacket preserves immutable observation lineage separately from derived renders.
14. SpectralObservation preserves instrument, calibration, uncertainty, wavelength bands, frame and provenance beneath display transforms.
15. External research/source acquisition gains attributable provenance receipts.
16. Hardware topology scoring supports CPU/GPU/accelerator/memory/network/optical-fabric evolution without claiming unavailable hardware.
17. Atlas levels 12→144→1,728→20,736→248,832 remain representational/addressing resolutions, never literal physical dimensions.
